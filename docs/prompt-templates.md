# 网球视频 AI 教练分析：Prompt 提示词模板与使用指南

本文档沉淀了在 `racket-video-lab` 项目中调用 AI 编码助手（如 Antigravity / Claude Code）进行长视频网球动作教练级分析时，最有效且可直接复用的 Prompt 模板。

---

## 一、 快速开启“AI 网球教练”分析（单指令标准版）

适用于给 AI 一个长视频文件，让其自主完成全套动作检索、逐帧拆解和教练级诊断：

```markdown
/goal 请充当专业网球教练，帮我分析位于 [本地视频路径，例如 ~/Downloads/tennis.MOV] 的击球视频。

执行要求：
1. 自动定位击球动作窗口（如正手抽球/反手/发球），采用粗细两级漏斗检索（音频静音检测+ROI局部裁剪），避免全局逐帧解码造成卡顿。
2. 提取 5 个关键生物力学阶段：准备预判 (Ready)、转肩引拍 (Unit Turn)、拍头下沉 (Lag & Drop)、触球瞬间 (Impact)、随挥收拍 (Follow-through)。
3. 输出包含：
   - 挥拍动图（GIF）与 5 阶段高清逐帧切片；
   - 生物力学诊断：分析转肩角度、动力链参与度、击球点前后位置、随挥延伸；
   - 针对性矫正训练方案（Drills）。
4. 生成可读性强的诊断报告与可视化预览。
```

---

## 二、 沉淀至工程项目 / 生成标准证据包（工程化落地版）

适用于分析完成后，让 AI 自动将分析产物保存为规范的案例目录并安全推送：

```markdown
请将刚才分析的视频片段与诊断结果作为标准样例（Gold Standard Example）沉淀到项目 [项目路径，例如 ~/Workspace/personal/projects/racket-video-lab]：

执行要求：
1. 建立样例目录（例如 examples/<stroke-type>/），保存 3~5 秒裁剪后的 H.264 MP4 片段、动图 GIF、以及 5 阶段高清关键帧切片。
2. 生成符合系统输出契约的 evidence.json，包含时间戳、关键相位、角度数据与诊断指标。
3. 编写案例 README.md，将所有媒体转为相对路径，确保在 GitHub 网页端能自动播放动图与表格排版。
4. 严格检查隐私与元数据（自动剥离 GPS/EXIF 信息），确认无敏感泄漏后自动提交并 push 到远程仓库。
```

## 三、 专项技术问诊（痛点驱动版）

适用于击球遇到瓶颈，想针对特定瑕疵进行专科会诊：

```markdown
我感觉自己最近【正手容易出底线 / 发球借不到腿部力量 / 双反击球点总是偏后受挤压】。
请帮我分析视频 [本地路径]：
- 重点盯防：[例如：拍头下沉是否充分 / 击球点与身体相对位置 / 随挥是否有雨刷式刷球]
- 给我指出导致该问题的最根本原因（Root Cause），并提供 2~3 个立竿见影的纠正练习法（Drills）。
```

---

## 四、 核心技巧与经验备忘

1. **善用 `/goal` 标签**：
   长视频涉及探测、采样、裁剪、生成动图等多步复杂工具调用。加入 `/goal` 可以让 Agent 自动闭环执行完整任务链，无需反复手动催促。
2. **传本地绝对路径，不要手动上传附件**：
   本地路径（如 `~/Downloads/xxx.MOV`）能让 Agent 直接调用本机的 FFmpeg / Python 工具链，不仅秒级读取，还能提取 60 FPS 无损原始帧。
3. **隐私脱敏保障**：
   所有输出给 GitHub 的切片媒体（MP4/JPG/GIF）都经过二次编解码，自带剥离 iPhone 原生拍摄定位（GPS/EXIF）的安全性。
