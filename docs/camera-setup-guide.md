# 网球自拍录像机位设置与拍摄指南（Camera Setup Guide）

要获得高精度的 AI 动作分析（特别是转肩、击球点与下肢动力链），**镜头的摆放位置决定了 70% 的分析准确度**。

在本次 Session #01 中，使用的是底线正后方的超远全景机位。为了在下次发球机训练（Session #02）中精准捕捉正手击球细节，请参考以下黄金拍摄方案：

---

## 一、 核心机位对比与推荐场景

```text
               [对方半场 / 发球机]
                     |
                     |  球飞来方向
                     v
================== [ 球 网 ] ==================
                     |
                     |
         (C) 正侧面 90° 机位
              [📱] ------------------> [ 👤 击球球员 ] (右手持拍)
                                           /
                                          /
                               (B) 后侧方 45° 黄金机位 ⭐
                                     [📱]
                     |
                     |
         (A) 正后方机位 (Session #01 机位)
                     [📱]
```

### 1. 机位 B：后侧方 45° 黄金机位 ⭐【强烈推荐，最佳兼顾】
* **摆放位置**：站在底线击球点**右后方约 3 ~ 4 米**，与击球方向呈 45° 夹角。
* **拍摄优势**：
  - **3D 视角俱佳**：既能看清**转肩深度**与后背蓄力，又能看清**击球点是否在身体前方**。
  - 能完整收录拍头下沉轨迹与随挥越过左肩的动作。
* **最适合**：发球机定点练习、综合正反手动作诊断。

---

### 2. 机位 C：正侧面 90° 专科机位【纠正击球点滞后最强】
* **摆放位置**：球场右侧边线旁（双打线外 1~2 米），正对你的击球准备站位，高度与腰平齐。
* **拍摄优势**：
  - **击球点尺标**：从侧面看，球与前脚掌、躯干的前后距离一清二楚（是不是击球点靠后被挤压，一目了然）。
  - 能清晰观察重心是从后脚向前脚 Step-in 还是后坐。
* **缺点**：看不到身体向后的转肩饱满度。

---

### 3. 机位 A：正后方机位（本次 Session #01 所用机位）
* **摆放位置**：底线后防护网正中央。
* **优缺点**：适合看比赛回合、站位战术与球的落点走向；但由于透视压缩（Foreshortening），较难精准测量击球点究竟在身体前方多少厘米。

---

## 二、 手机架设高度与距离黄金参数

| 参数项 | 推荐值 | 避坑提醒 |
| :--- | :--- | :--- |
| **高度 (Height)** | **1.0 ~ 1.3 米**（与腰部/髋关节等高） | ❌ **切忌放在地面仰拍**（球场反光大、透视畸变严重）<br>❌ **切忌挂在过高的铁丝网上俯拍**（压缩垂直挥拍轨迹） |
| **距离 (Distance)** | **3.5 ~ 5 米** | 手机画面中，**人物全身（头顶到脚底）应占据画面高度的 60%~75%**，避免人物过小导致夜间噪点模糊。 |
| **朝向 (Orientation)** | **横屏 (16:9)** 或 靠近时的 **竖屏 (9:16)** | 如果使用发球机定点打，横屏更容易收录球的来向与出球轨迹。 |

---

## 三、 手机相机拍摄参数设置（iPhone 建议）

为了让 AI 在逐帧拆解（特别是触球瞬间）不产生残影与动态模糊：

1. **帧率设置（最关键）**：
   - 打开 iPhone 【设置】->【相机】->【录制视频】；
   - 设为 **1080p @ 60 fps**（如果有条件，针对 1~2 次击球可使用【慢动作 1080p @ 120fps/240fps】）。
2. **曝光与锁定（AE/AF LOCK）**：
   - 手机架好后，长按屏幕对焦在**你的击球站位上**，锁定曝光与对焦（避免夜间灯光下画面忽明忽暗或频繁重新拉风箱对焦）。
3. **避开直射强光**：
   - 确保镜头不要正对球场大聚光灯直射，避免镜头眩光（Glare）遮挡人脸与球拍。
